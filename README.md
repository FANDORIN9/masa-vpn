# masa-vpn

VPN-сервис для продвинутых пользователей, которым важны стабильность, гибкая маршрутизация и понятная архитектура. Продукт ориентирован не только на Россию, а на международную аудиторию с фокусом на пользователей с IT-бэкграундом.

## Концепция продукта

Сервис строится как технологичный инфраструктурный продукт, а не как массовый consumer-VPN. Основные приоритеты — скорость подключения, предсказуемое качество, прозрачная система управления и отсутствие лишнего маркетингового шума.

## Техническая часть

В качестве ядра управления используется **Remnawave Panel** — центральный слой для оркестрации нод, пользователей и подписок. Решение разворачивается в защищённой схеме за reverse proxy, без прямого открытия сервисов в интернет. Remnawave позиционируется как мощный proxy management tool, построенный на Xray-core, с фокусом на простоту и удобство управления. [web:4][web:15]

Архитектура продукта должна поддерживать:
- несколько географически распределённых серверов;
- централизованное управление подписками и лимитами;
- масштабирование по мере роста нагрузки;
- отдельные роли для админов, саппорта и технической команды;
- интеграцию с ботом как основным пользовательским интерфейсом.

## Продуктовая база

Базовый функционал:
- автогенерация и выдача подписки через Telegram-бота/Web-сайт;
- выбор тарифов по количеству устройств, скорости или объёму трафика;
- автооплата и автопродление;
- ручная смена сервера или региона;
- базовая аналитика по активным пользователям и продлениям;
- уведомления о сроке окончания подписки, сбоях и новых функциях;
- реферальная механика для роста органики.

## Тарифная линейка

Рекомендуемая продуктовая линейка:
- **Start** — для одного устройства и минимального порога входа.
- **Pro** — для нескольких устройств и более гибкого выбора локаций.
- **Team** — для небольших команд и семей.
- **Trial / Test** — короткий доступ для проверки качества.

## Платежи

Платежная модель должна поддерживать криптовалюту, зарубежные банковские карты и СБП. [web:11]

## Telegram-бот

В качестве пользовательского слоя можно использовать готовый Telegram-бот SoloBot, который автоматизирует подписки, оплаты, уведомления и аналитику, а также работает с Remnawave. Это позволяет быстро запустить MVP и сразу закрыть ключевые сценарии покупки и обслуживания подписки. [web:5][web:13]

## Позиционирование

Сервис должен восприниматься как понятный и надёжный VPN для тех, кто ценит качество и контроль. Это решение для пользователей, которым нужен не просто доступ, а управляемая и масштабируемая сеть с современной технической основой.
